## Данные
Используется датасет:
**Recruitment Scam (EMSCAD)**  
Источник: https://www.kaggle.com/datasets/amruthjithrajvr/recruitment-scam

- Количество объектов: ~17 800  
- Количество признаков: 18  
- Таргет: `fraudulent`

Особенности:
- сильный дисбаланс классов (~5% мошеннических вакансий)
- наличие текстовых и категориальных признаков

## Модели

### 1. Baseline
- TF-IDF + Logistic Regression  

### 2. Дополнительная модель
- TF-IDF + RandomForest
